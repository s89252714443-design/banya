# Баня в лесу — лендинг

Одностраничный сайт бани на дровах в Дубне. Статика: HTML, CSS, картинки, шрифты и видео —
без сборки и зависимостей. Всё лежит локально, интернет для работы страницы не нужен.

Изначально страница была собрана на Tilda, поэтому вёрстка первого экрана и других секций
использует её «zero-блоки». Ниже описано, как с этим работать, чтобы ничего не разъехалось.

## Структура

```
.
├── index.html              # вся разметка страницы одним файлом
├── assets/
│   ├── css/                # стили Tilda + свои правки
│   │   ├── custom.css                          # ← ВСЕ РУЧНЫЕ ПРАВКИ ЗДЕСЬ
│   │   ├── google-fonts.css                    # @font-face -> assets/fonts/
│   │   ├── tilda-grid-3.0.min.css
│   │   ├── tilda-blocks-page43426613.min.css   # основные стили блоков
│   │   ├── tilda-animation-2.0.min.css
│   │   └── tilda-popup-1.1.min.css
│   ├── js/                 # 15 файлов: jQuery + библиотеки Tilda
│   ├── media/              # 97 изображений: jpg, png, svg
│   ├── fonts/              # 10 файлов woff2 (Manrope, Oranienbaum)
│   └── video/              # видео для секции «Помогаем»
├── .nojekyll               # чтобы GitHub Pages отдавал папку assets как есть
└── .claude/launch.json     # конфиг локального dev-сервера
```

## Локальный запуск

Открывать `index.html` двойным кликом **не нужно**: по протоколу `file://` часть скриптов Tilda
не работает и вёрстка разъезжается. Нужен любой статический сервер:

```bash
npx -y serve .
```

Команда выведет адрес — обычно http://localhost:3000.

## Как устроена вёрстка и как её править

### Тексты

Прямо в `index.html`. Разметка не минифицирована, поиск по фразе находит нужное место сразу.
Текст лежит внутри `<div class='tn-atom'>`.

### Положение и размеры элементов

Главное, что нужно знать: **позиции задаются атрибутами `data-field-*`, а не CSS**.
Готовые CSS-правила в файле хранят устаревшие значения — при загрузке скрипт Tilda
пересчитывает всё заново из атрибутов и проставляет инлайн-стили. Поэтому править нужно атрибуты:

```
data-field-left-value="55"        # ≥1200 px
data-field-left-res-960-value="40"    # 960–1199
data-field-left-res-640-value="40"    # 640–959
data-field-left-res-320-value="30"    # <640
```

Значения — в «дизайнерских» пикселях сетки (1200 / 960 / 640 / 320), а не в экранных.
Блок масштабируется через `transform`, поэтому на экране 1440 px всё умножается примерно на 1.19.
Сравнивать ширину текста с шириной блока нужно **в одних единицах**, иначе строка неожиданно
переносится.

### Привязка к низу

У элементов с `data-field-axisy-value="bottom"` нижняя граница считается как
`высота_окна + top × масштаб` и **не зависит от высоты самого элемента**.
Удобно: чтобы выровнять низ двух элементов, достаточно дать им одинаковый `top`.

### Чего делать не надо

Не прописывайте блокам жёсткую высоту — ни инлайн, ни правилом вида
`#recNNN .t396__artboard { height: 955px !important; }`. Такие значения ломают адаптивность:
на широких экранах текст налезает на соседние блоки.

### Два блока на каждую секцию

Первый экран существует в двух копиях: `#rec702381407` — для экранов от 640 px,
`#rec718123242` — для более узких. Правки в тексте нужно вносить **в оба**,
а в геометрии — обычно только в тот блок, который отвечает за нужную ширину.

### Стили

Свои правила — в `assets/css/custom.css`, он подключён последним и перебивает базовые.
Там же оформление элементов, добавленных вручную (кнопка «Забронировать», надпись
над заголовком), затемнение фона и поведение меню при наведении.

Файлы Tilda лучше не трогать: они минифицированы, и любая правка в них потеряется,
если понадобится обновить библиотеку.

### Анимация появления

Задаётся атрибутами `data-animate-sbs-opts`: `ti` — длительность, `dt` — задержка в мс.
Элементу также нужен класс `t396__elem--anim-hidden` и правило `opacity: 0` под его id —
в Tilda такое правило пишется отдельно для каждого элемента.

Текущая последовательность: заголовки — 1500 мс, надпись над ними — 2100 мс.

## Публикация на GitHub Pages

**Settings → Pages → Source: Deploy from a branch → `main` / `(root)`.**
`.nojekyll` уже добавлен. Все пути в разметке относительные, поэтому сайт работает
и в подпапке репозитория.

## Что стоит поправить перед запуском на своём домене

- **Описание для поисковиков.** В `<head>` теги `description` и `og:description`
  остались от прежнего сайта — именно этот текст покажет поисковая выдача.
- **`<link rel="canonical">` и `og:url`** указывают на сторонний домен. Если оставить,
  поисковики сочтут оригиналом чужой сайт.
- **Favicon** — иконка вкладки пока прежняя.
- **Счётчик статистики Tilda.** Скрипт с `id="tildastatscript"` продолжает обращаться
  к серверам Tilda. Если не нужен — удалите тег из `index.html`.
- **Видео.** `assets/video/banya-atmosphere.mp4` (720×728, 1,5 МБ) обрезано под
  квадратный слот в секции «Помогаем» и уменьшено под экранный размер. Исходный
  вертикальный ролик 1080×1920 остался в истории git, если понадобится другой кадр.
