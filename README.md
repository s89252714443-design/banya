# Спа-комплекс на Алтае «Сила Духа»

Полностью автономная копия сайта [spasiladuha.ru](https://spasiladuha.ru/) (исходно собран на Tilda).
Все стили, скрипты, изображения и шрифты скачаны локально — интернет для работы сайта не нужен.

## Структура

```
.
├── index.html              # Вся разметка страницы (один файл)
├── assets/
│   ├── css/                # Стили Tilda + подключение шрифтов
│   │   ├── google-fonts.css        # @font-face, ссылается на assets/fonts/
│   │   ├── tilda-grid-3.0.min.css
│   │   ├── tilda-blocks-page43426613.min.css   # ← основные стили блоков страницы
│   │   ├── tilda-animation-2.0.min.css
│   │   └── tilda-popup-1.1.min.css
│   ├── js/                 # jQuery + библиотеки Tilda (zero-блоки, меню, попапы, анимации)
│   ├── media/              # 156 изображений: jpg, png, webp, svg
│   └── fonts/              # 10 файлов woff2 (Manrope, Oranienbaum)
└── .claude/launch.json     # Конфиг локального dev-сервера
```

## Локальный запуск

Открывать `index.html` двойным кликом не стоит — часть скриптов Tilda не работает по протоколу `file://`.
Нужен любой статический сервер:

```bash
npx -y serve .
```

Затем открыть адрес, который выведет команда (обычно http://localhost:3000).

## Как вносить правки

- **Тексты и содержимое блоков** — прямо в `index.html`. Разметка не минифицирована,
  блоки размечены как `<div class="t396" id="rec...">`, поиск по нужной фразе находит место сразу.
- **Стили** — `assets/css/tilda-blocks-page43426613.min.css`. Файл минифицирован;
  для точечных правок удобнее дописывать свои правила в конец файла или завести
  отдельный `assets/css/custom.css` и подключить его последним в `<head>`.
- **Картинки** — заменить файл в `assets/media/` с тем же именем, либо положить новый
  и поправить `src` / `srcset` в `index.html`.
- **Якорные ссылки меню** (`#about`, `#program`, `#rev`, `#contacts`, `#who`, `#ind`)
  уже переведены на относительные — навигация работает внутри копии.

## Что осталось внешним (и почему)

Это не ошибки копирования — просто ссылки, которые ведут наружу по своей природе:

- `assets/js/tilda-stat-1.0.min.js` — счётчик статистики Tilda. Работать сайту не мешает,
  но продолжает стучаться на серверы Tilda. Если он не нужен — удалите тег `<script>` с
  `id="tildastatscript"` из `index.html`.
- `<link rel="canonical">` и `og:*` в `<head>` указывают на боевой домен — их стоит поменять
  на новый адрес перед публикацией.
- Иконки сайта (`favicon`, `apple-touch-icon`) и внешние ссылки в подвале.

## Формы

Форм обратной связи в разметке нет — все кнопки открывают попапы или ведут по якорям.
Ничего перенастраивать при переносе не требуется.
